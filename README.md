**Cari Bedanya!** — a spot-the-difference game with 3 original scenes drawn procedurally on canvas (Pasar Pagi morning market, Pelabuhan Senja sunset harbour, Taman Kota city park), 7 differences in every level, a timer, score, 3 hints per level, keyboard play (arrow keys + Enter), WebAudio sound effects, and a win screen with stars. It runs entirely offline from its own static files.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. No build step, no network requests, no external files.

## How to play

- Compare picture **A** (left) with picture **B** (right) and click or tap every difference you spot — found ones get a green circle and check mark.
- Each difference is worth +100 points, a wrong click costs −25, and the 💡 hint button (3 per level, −50) pulses a ring around one difference you haven't found yet.
- Keyboard: arrow keys move the crosshair cursor, Enter or Space marks the spot, H asks for a hint, M toggles sound.
- Find all 7 differences to clear the level and earn a time bonus; pick the next level from the level-select screen.
